# Stroke Risk Prediction Using Machine Learning

## 📌 Project Overview
This project predicts the risk of stroke using Machine Learning techniques based on healthcare data such as age, BMI, glucose level, hypertension, smoking status, and heart disease.

The system helps healthcare professionals identify high-risk patients early and supports preventive healthcare decision-making.

---

## 🚀 Features
- Stroke risk prediction using ML algorithms
- Data preprocessing and analysis
- Real-time prediction using Streamlit
- Interactive healthcare dashboard using Power BI
- Multiple algorithm comparison

---

## 🧠 Machine Learning Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

---

## 📊 Dataset Features
| Feature | Description |
|---------|-------------|
| Age | Patient age |
| Gender | Male/Female |
| Hypertension | Blood pressure condition |
| Heart Disease | Heart-related disease |
| BMI | Body Mass Index |
| Avg Glucose Level | Blood sugar level |
| Smoking Status | Smoking habits |
| Stroke | Target variable |
